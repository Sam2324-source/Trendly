TRENDLY — Fashion E-Commerce Website
=====================================
A responsive front-end fashion shopping website built with HTML5, CSS3 and vanilla JavaScript.

FILES
- index.html: page structure and content
- style.css: styling and responsive layout
- script.js: product catalogue and interactive features

FEATURES
1. Responsive home page and navigation
2. 12 sample fashion products
3. Product search
4. Category filters: Women, Men and Accessories
5. Sort by price or name
6. Shopping cart: add, remove and change quantities
7. Wishlist
8. Subtotal and shipping calculation
9. Demo checkout and order confirmation
10. Newsletter form demo
11. Cart and wishlist saved using browser LocalStorage

HOW TO RUN
1. Extract the ZIP file.
2. Keep all three website files in the same folder.
3. Open index.html in Chrome, Edge or Firefox.
4. Internet is needed for Google Fonts and remote product photographs.

DEMONSTRATION CHECKLIST
- Search for "shirt".
- Filter by Women or Accessories.
- Sort by price.
- Add products to the bag.
- Change quantity and remove a product.
- Save a product to the wishlist.
- Refresh the page to demonstrate LocalStorage.
- Complete checkout using sample details.

IMPORTANT
This is an educational front-end demo. It does not process real payments, store orders on a server, or send newsletter subscriptions. Do not enter real sensitive information.

TECHNOLOGIES
HTML5, CSS3, JavaScript ES6, DOM manipulation, LocalStorage.
